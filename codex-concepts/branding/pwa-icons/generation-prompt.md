# PWA icon design prompt

Built-in image generation. Reference: `../neon-fox-logo-v1.png`.

Use case: logo-brand.
Design one polished square PWA app icon for Neon Fox, using the attached game logo ONLY as a reference for the fox's identity and palette. This is a new icon, not a cropped wordmark.
Subject: the same adorable orange fox head, cream cheeks and ear interiors, bright amber eyes, cheerful mischievous smile, pointed ears, little swept orange forelock. Simplify the shapes and highlights so it reads clearly at 48 pixels. Confident clean cartoon contours, subtle dimensional shading, restrained cyan rim light, strong orange-versus-midnight contrast. A small simple curved cyan/orange orbit accent below the chin can evoke the neon racing trail, but prioritize the face. No text, letters, words, numbers, full body, or additional animals.
Composition: centered fox head, including BOTH complete ears, wholly inside a centered circular safe zone of radius 36% of the canvas width. Fox head occupies about 58–62% of the canvas width and height, with substantial balanced surrounding space. All meaningful artwork must stay within that circle; do not draw the circle. This padding is essential for Android maskable PWA icons. Do not crop the ears.
Background: completely opaque full-bleed uniform deep midnight navy #071426 reaching all four edges and all four square corners. No transparency. No baked rounded corners, no border frame, no phone mockup, no checkerboard. The operating system will apply its own shape.
Output: one finished 1024 by 1024 pixel square app icon. Single icon, not a contact sheet. Preserve the friendly fox character and orange/cyan identity of the reference while simplifying for small-size legibility.
